## The purpuse of those script
These scripts were written for my undergraduate research project, which focused on the study of expression patterns and the quantification of various long non-coding RNAs expressing satellite DNA repeats in Drosophila sp.

## Colocalisation script
The script for the colocalisation analisi as been made to calculate the 2D colocalisation of the ovariole and the 3D volume of the transcript inside the oocyte in various Drosophila species. Futhermore, the JACoP2 plugin as been used as the core tool for the analysys. 
Nevertheless, those script can be useful to anyone who desire to make a automatic colocalisation analysis script.
