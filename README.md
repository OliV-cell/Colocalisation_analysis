correctly. But anyway, with that said, less discussion of the content.

## The purpose of those scripts
These scripts were written for my undergraduate research project, which focused on studying expression patterns and quantifying various long non-coding RNAs associated with satellite DNA repeats in Drosophila sp.

## Colocalization script
The script for the colocalization analysis has been made to calculate the 2D colocalization of the ovariole and the 3D volume of the transcript inside the oocyte in various Drosophila species. Furthermore, the JACoP2 plugin has been used as the core tool for the analysis. 
Nevertheless, those scripts can be useful to anyone who desires to make an automatic colocalization analysis script.
