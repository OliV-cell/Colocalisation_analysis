# Why Julia
I wanted to learn a new language that was more efficient than R, especially for large datasets,
and Julia seems like a great choice, since it kinda solves the 2 languages problem. Nevertheless, all the statistical analyses can be done in RStudio if you are using the [JuliaCall](https://github.com/JuliaInterop/JuliaCall)
package or by adapting the code yourself.
