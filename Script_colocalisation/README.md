# 💻 R Scripts for Colocalization Analysis

This folder contains R scripts designed to process and analyze the output data generated by the Fiji colocalization macros.

## 🛠️ Data Processing Function

If you simply need the core function to parse and extract colocalization scores from the generated `.csv` or `.txt` output files, you can use the `Traitement_data_coloc` function below.

This function reads the raw output from the JACoP plugin and structures the following metrics into a clean R `data.frame`:
- **Pearson's Coefficient**
- **Overlap Coefficient**
- **k1 & k2** (r² = k1 × k2)
- **Manders' Coefficients (M1 & M2)**
- **Cytofluorogram parameters (a & b)**
- **Intensity Correlation Quotient (ICQ)**

### 📝 Usage

```R
Traitement_data_coloc <- function(tableau_data_souce) {
  
  # Initialize the data frame to store all metrics
  indice_coloc <- data.frame(
    Coef_pearson = numeric(0),
    Coeaf_overlap = numeric(0),
    k1  = numeric(0),
    k2 = numeric(0), 
    M1 = numeric(0),
    M2 = numeric(0),
    a_cytofluogram  = numeric(0),
    b_cytofluogram = numeric(0), 
    ICQ = numeric(0),
    stringsAsFactors = FALSE
  )
  
  # Temporary row to store current loop metrics
  new_row <- rep(0, 9)
  n <- 1
  
  # Iterate through the raw text file to find and extract scores
  for (i in 1:nrow(tableau_data_souce)) {
    
    if (grepl("Pearson's Coefficient:", tableau_data_souce[i, 1], fixed = TRUE)) {
      new_row[1] <- tableau_data_souce[i + 1, 1]
    }
    
    if (grepl("Overlap Coefficient:", tableau_data_souce[i, 1], fixed = TRUE)) {
      new_row[2] <- tableau_data_souce[i + 1, 1]
    }
    
    if (grepl("r^2=k1xk2:", tableau_data_souce[i, 1], fixed = TRUE)) {
      new_row[3] <- tableau_data_souce[i + 1, 1]
      new_row[4] <- tableau_data_souce[i + 2, 1]
    }
    
    if (grepl("Manders' Coefficients (using threshold", tableau_data_souce[i, 1], fixed = TRUE)) {
      new_row[5] <- tableau_data_souce[i + 1, 1]
      new_row[6] <- tableau_data_souce[i + 2, 1]
    }
    
    if (grepl("Cytofluorogram's parameters:", tableau_data_souce[i, 1], fixed = TRUE)) {
      new_row[7] <- tableau_data_souce[i + 1, 1]
      new_row[8] <- tableau_data_souce[i + 2, 1]
    }
    
    if (grepl("ICQ: ", tableau_data_souce[i, 1], fixed = TRUE)) {
      new_row[9] <- tableau_data_souce[i, 1]
      
      indice_coloc[n, ] <- new_row
      
      n <- n + 1
      new_row <- rep(0, 9)
    }
  }
  
  # Clean all non-numeric characters and convert to numeric data types
  indice_coloc[] <- lapply(indice_coloc, function(x) {
    as.numeric(sub(".*[:=]\\s*([-0-9eE\\.]+).*", "\\1", x))
  })
    
  return(indice_coloc)
}
```

> **Tip:** You can `source()` this function into your R environment and pass the raw `read.csv()` or `read.delim()` output as the `tableau_data_souce` argument to instantly structure your results.
