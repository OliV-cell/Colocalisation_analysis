# Julia Analysis Scripts

## Overview
This folder contains Julia scripts for colocalization analysis, developed as part of a research initiation project. The analysis includes statistical computations and visualization of colocalization heatmaps.

## Why Julia?

I chose Julia for this analysis because:
- **Efficiency**: Julia offers better performance than R for large datasets
- **Solves the Two-Language Problem**: Julia combines the ease of use of Python/R with the speed of compiled languages
- **Visualization**: Julia produced high-quality heatmaps, as shown below

**Note**: All statistical analyses can also be performed in RStudio using the [JuliaCall](https://github.com/Non-Contradiction/JuliaCall) package or by adapting the code to R.
